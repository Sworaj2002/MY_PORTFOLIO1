# MY_PORTFOLIO1

A personal portfolio website showcasing my skills, projects, education, and experience as a Full-Stack Developer. This portfolio highlights my journey, expertise, and accomplishments in software development, along with links to my work and contact details.

## 🚀 Features

- **About Me**: An introduction to my professional background and objectives.
- **Projects**: Detailed descriptions of my key projects with technologies used and responsibilities.
- **Skills**: A categorized list of my technical skills and tools.
- **Education**: Academic qualifications and relevant coursework.
- **Experience**: My professional work experience.
- **Certifications**: Certifications and accomplishments in various domains.
- **Hobbies**: Personal interests and activities.
- **Contact Information**: Links to email, LinkedIn, GitHub, and HackerRank.

### 🛠️ Technologies Used - HTML, CSS, JAVASCRIPT
